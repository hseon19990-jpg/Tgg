# بوت الرسائل المجهولة

## المتغيرات (Railway → Variables)
| المتغير | الوصف |
|---|---|
| BOT_TOKEN | توكن البوت من @BotFather (مطلوب) |
| OWNER_ID | أيدي حسابك (مطلوب) |
| LINK_CODE | كود الرابط الخاص (اختياري، وإلا يُولَّد تلقائياً) |
| REQUIRE_LINK | true = لا يراسلك إلا من دخل عبر رابطك الخاص، false = يكفي اليوزر |
| TIMEZONE | مثل Asia/Riyadh (الافتراضي UTC) |
| DB_PATH | مسار قاعدة البيانات، مثل /data/bot.db |
| WELCOME_TEXT | نص الترحيب (اختياري) |

## النشر
1. ارفع الملفات إلى مستودع GitHub.
2. في Railway: New Project → Deploy from GitHub repo.
3. أضف المتغيرات أعلاه.
4. **مهم:** أضف Volume في Railway واربطه على المسار `/data` وضع `DB_PATH=/data/bot.db`، حتى لا تضيع قائمة المحظورين عند إعادة النشر.
5. أرسل /start للبوت من حسابك لتظهر لك لوحة المالك ورابطك الخاص.

## الاستخدام
- رابطك: `https://t.me/اسم_البوت?start=الكود` (يظهر في /start و /settings).
- للحظر: رد (Reply) على رسالة المرسل ثم اضغط «حظر المرسل»، أو اكتب «حظر» كرد مباشر، أو من /settings بالأيدي.
- رفع الحظر: من /settings (بالأيدي أو من قائمة المحظورين).
